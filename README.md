# Micronaut Netty HTTP Client

[English](README.md) | [简体中文](README.zh-CN.md)

`micronaut.http.client.netty@1` provides the Netty implementation of Micronaut HTTP Client 5.1.13 and depends on the public API of `micronaut.http.client@1`. A runnable example is in `micronaut/http/client/netty/Main.norm`.
