# micronaut-http-client-netty sample ownership

[English](README.md) | [简体中文](README.zh-CN.md)

This module supplies the Netty transport for client requests. The runnable scenario is owned by [micronaut-http-client](https://github.com/normlanguage/micronaut-http-client/tree/main/samples) in its `samples/` directory; use that example to observe the behavior through the public API.

The module identity and pinned dependencies are defined in [module.norm](../micronaut/http/client/netty/module.norm).
